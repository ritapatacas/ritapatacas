## Overview

I'm a full-stack developer and tech educator with a background that spans software engineering, artificial intelligence and film post-production.

I've worked on production applications using React, Redux, Node.js and PostgreSQL, contributed to enterprise platforms with Mendix, and spent the last few years teaching software development and emerging technologies.

Since 2024, I've been designing and delivering practical training in Artificial Intelligence, AI-assisted development, JavaScript and Data Analysis. More than 200 learners trained so far.

Before software, I spent nearly a decade in film editing and post-production. Different tools, same obsession with getting the details right.

## Changelog


**Tech Instructor — Code for All_**  
*September 2024 – Present*

Designing and delivering practical courses in Artificial Intelligence, AI-assisted development, JavaScript and Data Analysis. Responsible for course materials, exercises, projects and assessments. Over 200 learners trained.

**Programming Workshop Leader — TUMO**  
*September 2025 – Present*

Leading project-based programming workshops for teenagers, focused on problem-solving and self-directed learning.

**Software Developer (Mendix) — Bool / TCS / PostNL**  
*June 2024 – 2025*

Developed features for PostNL's logistics and parcel-management platform as part of an international delivery team. Earned Mendix Rapid and Intermediate Developer certifications.

**Full-Stack Developer & Bootcamp Instructor — Code for All_**  
*May 2022 – May 2024*

Worked on internal admissions and back-office platforms using React, Redux, Node.js, Objection.js and PostgreSQL. Also taught Java, OOP, algorithms, databases, concurrency, networking and full-stack web development.

Contributed to course materials, student code reviews and the design of a Unity game-development course.

**Film Editor & Post-Production**  
*2012 – 2020*

Worked on feature films, documentaries and animation, with projects screened at Locarno, Cannes, Berlin and Venice. Editor and post-producer of the award-winning animated short *Estilhaços* (2016).
